
Finderの右クリックメニューから、選択したファイル・フォルダをパスワード付きzipに圧縮するAutomatorクイックアクション。

## 概要

- Finderで選択した項目を、パスワード付きzip(`zip -e` 相当)に圧縮します。
- 出力先は、選択した項目と同じフォルダです。
- 複数選択した場合は、1つの `アーカイブ.zip` にまとめて圧縮されます。
- 単一選択の場合は、`元のファイル名.zip` という名前で出力されます。
- 完了後、Finderで作成したzipの場所を自動的に表示します。

## 注意事項

- ここで使う暗号化は、zip標準の簡易的な方式であり、強度は高くありません。
- 機密性が高いファイルを扱う場合は、KekaなどのアプリでAES-256暗号化のzipや7zを作成してください。

## 動作環境

- macOS(Finder、Automator)
- Automatorの「AppleScriptを実行」アクションを使用します(シェルスクリプトのアクションは、Finderの選択項目を正しく受け取れないため使用していません)。

## インストール

1. Automatorを開き、「新規書類」→「クイックアクション」を選択します。
2. ワークフロー上部の設定を以下にします。
   - 次の選択項目を受け取る: `ファイルまたはフォルダ`
   - 検索対象: `Finder.app`
3. アクション一覧から「AppleScriptを実行」を追加し、`src.applescript` の内容を貼り付けます。
4. 「パスワード付きzipに圧縮」など、分かりやすい名前で保存します。

## 使い方

1. Finderで、圧縮したいファイルまたはフォルダを選択します。
2. 右クリック→「クイックアクション」→保存した名前を選びます。
3. パスワードを入力します。
4. 完了すると、作成したzipの場所がFinderで表示されます。

## 有効化(初回のみ)

クイックアクションが右クリックメニューに表示されない場合は、以下を確認してください。

- 「システム設定」→「キーボード」→「キーボードショートカット」→「サービス」で、該当のアクションにチェックが入っているか。
- 「システム設定」→「プライバシーとセキュリティ」→「オートメーション」で、AutomatorからFinderへの操作が許可されているか。

## 既知の制約

- 対象がiCloud Drive上にあり、実体がまだMacにダウンロードされていない場合、正しく動作しないことがあります。その場合は、対象を右クリックして「今すぐダウンロード」を実行してから再度お試しください。
